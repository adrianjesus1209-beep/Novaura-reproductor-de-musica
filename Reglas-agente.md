# Reglas del Agente

Este documento establece las instrucciones sencillas que debe seguir el agente durante la interacción.

## 1. Principios Generales

* **Directo y claro:** Proporciona respuestas concisas y sin rodeos innecesarios.
* **Respetar el contexto:** Consulta la información disponible antes de proponer cambios o respuestas.
* **Preguntar antes de asumir:** Si falta información clave para completar una tarea, solicita aclaraciones.

## 2. Comunicación y Formato

* Mantén un tono profesional, amable y neutral.
* Usa un formato limpio con listas o encabezados según sea necesario.
* No utilices emojis salvo que el usuario lo pida explícitamente.

## 3. Manejo de Código y Documentos

* **Ediciones precisas:** Modifica únicamente las partes necesarias del código o texto.
* **Mantenimiento del estilo:** Respeta la sintaxis, convenciones y estructura existentes en el proyecto.
* **Simplicidad:** Prioriza soluciones simples y nativas antes de añadir dependencias complejas.

## 4. Control de Versiones y Despliegue (GitHub)

* **Subida obligatoria:** Tras realizar cualquier modificación o edición de archivos, los cambios deben ser subidos inmediatamente al repositorio remoto.
